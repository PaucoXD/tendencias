# Radar de Tendencias

Página personal para juntar tendencias e ideas para el negocio de **playeras** e **invitaciones**.

Incluye:
- **Próximas temporadas**: cuenta regresiva a fechas de venta en México (Día de Muertos, Navidad, Día de las Madres, graduaciones…) y cuándo empezar a vender.
- **Tendencias**: tarjetas filtrables (Playeras / Invitaciones / Combos) con una idea concreta para vender y links a Pinterest, Etsy y TikTok.
- **Buscar en vivo**: escribe una palabra y abre Google Trends, Pinterest, TikTok, Etsy, Mercado Libre, Canva y más con esa búsqueda.
- **Mi libreta de ideas**: guarda ideas (se quedan en tu navegador).

## Cómo abrirla
Abre `index.html` en el navegador, o actívala en GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
Para agregar o cambiar tendencias, edita las listas `TRENDS` y `EVENTS` dentro de `index.html`.
